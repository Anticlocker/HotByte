The HotByte DigiMenu platform is built using a robust, high-performance Full-Stack JavaScript architecture. It is designed to be extremely fast by avoiding heavy frontend frameworks, relying instead on a "Vanilla" approach that ensures near-instant load times on mobile devices.

Here is the detailed breakdown of the stack and its components:

1. Core Technology Stack
Frontend (The "Eyes")
Language: Vanilla HTML5 & CSS3 (Custom Design System).
Logic: Pure JavaScript (ES6+). No React/Vue overhead, which keeps the page size tiny for slow restaurant Wi-Fi.
Styling:
Bootstrap 5.3: Used primarily for the responsive grid system.
Custom CSS: Extensive use of CSS Variables (--primary, --bg-midnight) for a unified "Midnight & Fire" theme.
Glassmorphism: Advanced CSS filters for a premium, modern feel.
Typography: Google Fonts (Outfit for bold headings, Inter for clean readability).
Icons: FontAwesome 6.4 (Pro-style implementation).
Backend (The "Brain")
Environment: Node.js.
Framework: Express.js (High-speed routing).
Database: PostgreSQL (Enterprise-grade relational database).
Authentication:
Customers: OTP-based login (via Message Central).
Admins: Secure Username/Password with session-based persistence in the database.
Security: express-rate-limit (prevents bot attacks), helmet-style security headers, and parameterized SQL queries to prevent injection.
2. Integration Components (Third-Party)
Payment Gateway: Razorpay (Integrated for UPI, Cards, and Netbanking).
Messaging: Message Central (Used for sending secure OTPs for user verification).
Push Notifications: OneSignal (Sends real-time order updates to customers).
Content Delivery (CDN): BunnyCDN (Serves menu images from global edge locations for maximum speed).
Modals & Alerts: SweetAlert2 (Used for professional, non-blocking user feedback).
3. Key Functional Components
A. Digital Menu Engine
Dynamic Loading: Fetches menu items from PostgreSQL based on categories.
Smart Cart: Client-side state management using localStorage so the cart isn't lost if the page is refreshed.
Availability Toggle: Real-time "Sold Out" status indicators.
B. Admin Control Center
Live Dashboard: Real-time statistics using custom SQL aggregations (json_agg).
Order Manager: A kanban-style interface for moving orders from Pending → Preparing → Completed.
Kitchen Display System (KDS): A dedicated, auto-refreshing view for chefs to see incoming orders instantly.
C. Analytics & Reporting
Sales Tracking: Built-in logic to calculate daily revenue, top-selling items, and customer growth.
Rating System: Integrated feedback loop allowing customers to rate items, which then reflects on the menu.
4. Deployment & Infrastructure
Domain: rav1.in (Production environment).
Hosting: Optimized for platforms like Railway or Heroku with a "Trust Proxy" setup for secure HTTPS handling.
Storage: Images are managed via URL pointers to BunnyCDN, keeping the local server lightweight.
Summary Architecture
Layer	Technology
Interface	HTML5 / CSS3 / Vanilla JS
API	Node.js / Express
Data	PostgreSQL
Auth	OTP / Session Management
Payments	Razorpay
Speed	BunnyCDN / Vanilla JS (No Framework)
This stack makes HotByte one of the fastest digital menu platforms available, ensuring that even on weak 4G/5G connections inside a restaurant, the menu opens in under 1 second.
